How KNN works

K-nearest neighbour is a lazy, instance-based classifier. To label an unknown observation, it finds the K closest stored examples and assigns the majority class. In this lab, a vote tie is resolved using the smaller total neighbour distance.

Distance and scaling

Euclidean distance follows a straight line; Manhattan distance follows grid steps; Minkowski generalises both. KNN depends on distances, so real dataset features are z-score standardized before classification.
